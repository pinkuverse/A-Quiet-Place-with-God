# A Quiet Place with God

A small devotional website: Bible study notes, a reading schedule, a prayer journal, worship links and personal notes.
Entries are saved in the visitor's own browser (localStorage). Nothing is sent to a server.

## Files

- `index.html` - the page structure
- `css/style.css` - all the colors, fonts and layout
- `js/app.js` - everything interactive (saving, lists, backup, passcode)

## Run it on your computer

Open `index.html` in a browser.

## Publish

Push to the `main` branch, then Settings > Pages > Deploy from a branch > `main` / `(root)`.
